## Emergency Procedures

### How to Page On-Call
1. **PagerDuty**: Call 1-844-800-7243 or use mobile app
2. **Slack**: Post in #gitvan-incidents with @oncall mention
3. **Phone**: Call primary on-call mobile (above)
4. **If no response in 5 min**: Call secondary on-call

### How to Escalate
1. Try primary contact (on-call or assigned person)
2. If no response in 10 minutes, escalate to next level
3. For critical issues (P1), escalate immediately to management
4. Document all escalation attempts

### War Room Activation (P1 Only)
1. Create Slack channel: `#incident-YYYYMMDD-HHMM`
2. Post in #gitvan-incidents: "@channel War room: #incident-YYYYMMDD-HHMM"
3. Start Zoom meeting (link above)
4. Page: Incident Commander, Operations, Development, Communications
5. Invite management if > 30 minutes
