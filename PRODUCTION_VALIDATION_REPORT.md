**Sensitive/Development files being published:**

- Bloated package size (5.7MB vs expected 2MB)
- Confusing for users (328 files vs expected ~50-100)
- Violates principle of minimal package distribution

**Root Cause:** `.npmignore` exists but is being overridden or not comprehensive enough.

### 🔴 Missing npm Package Configuration

The package requires these fields to be usable:

```json
{
  "type": "module",
  "main": "./dist/cli.mjs",
  "module": "./dist/cli.mjs",
  "bin": {
    "gitvan": "./dist/bin/gitvan.mjs"
  },
  "exports": {
    ".": {
      "import": "./dist/cli.mjs",
      "types": "./dist/cli.d.ts"
    },
    "./package.json": "./package.json"
  },
  "engines": {
    "node": ">=18.0.0"
  },
  "files": [
    "dist",
    "LICENSE",
    "README.md",
    "CHANGELOG.md"
  ]
}
```

**Without these fields:**
- ❌ `npm install -g gitvan` won't create CLI command
- ❌ `import { } from 'gitvan'` won't resolve
- ❌ Node version constraints not enforced
- ❌ All 328 files published instead of necessary ~50
